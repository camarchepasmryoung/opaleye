# 6. 사실 체크 — 다 만든 뒤 반드시 (2026-11-09 시영)

덱을 다 만들면 **올리기 전에** 이 체크리스트를 통과해야 한다. 통과 못 하면 `status`를 `검수완료`로 올리지 않는다.

## 어떻게
1. 덱 폴더에 `source.md`를 만든다: 카드 문장 ↔ 원문(자막 시각·페이지·데이터 파일) 대조표.
2. 맨 아래에 아래 체크리스트를 붙이고, 하나씩 확인한 것만 `- [x]`로 바꾼다.
3. 렌더러(`render.mjs`)는 `source.md`가 없거나 `- [ ]`가 남아 있으면 경고를 띄운다. 대시보드도 덱마다 `사실 체크 ✓ / 미완`을 보여 준다.

## 체크리스트 (복사해서 source.md 맨 아래에)
```
## 사실 체크
- [ ] 1. 모든 숫자·인용에 원문 위치(자막 시각 / 페이지 / 데이터 파일)가 붙어 있다
- [ ] 2. 남의 영상이 인용한 주장(예: "유튜브가 이렇게 말했다")은 1차 출처(유튜브 공식 블로그·도움말 등)까지 확인했다. 못 찾으면 "~라고 해요"로 쓰고 표에 ❓ 표시
- [ ] 3. 원문의 단서(증명은 아님, 일부만, 예측값, 몇 년 기준)를 카드에서 지우지 않았다
- [ ] 4. 내 채널 숫자는 잘된 것만 고르지 않았다 — 같은 기간 전부 보여 주거나 중앙값을 같이 적었다
- [ ] 5. 날짜·기준 시점을 붙였다 (예: 2018년 발표, 2026년 11월 기준)
- [ ] 6. "무조건·100%·반드시" 같은 과장이 없다
- [ ] 7. 사례 하나로 원인을 단정하지 않았다
```

## 게시물 글·표지 후보도 대상
- `post`에는 `source.md`에 있는 사실만 쓴다.
