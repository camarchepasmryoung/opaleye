# 4. 운영

## 주간 흐름 (목표)
1. 주 7개를 한 번에 만든다. 덱 폴더 `decks/YYYY-MM-DD_<주제>/` — 날짜 = 발행일.
2. 시영이 하루 날 잡고 대시보드에서 검수한다 → 수정 요청을 복사해 Claude에게 붙여 넣는다.
3. 검수가 끝난 덱은 `deck.mjs`의 `status`를 `검수완료`로 바꾼다.
4. 발행 (2026-11-09 시영 고정 규칙): **흰지로의 오답노트 채널 커뮤니티**에 이미지 전부 + 게시물 글(post)을 넣어 올린다. 당일 덱은 즉시 게시, 나머지는 **매일 오전 7시(한국 시간) 예약**. 시영이 따로 말하지 않아도 이 방식. 유튜브 데이터 API에는 게시물 기능이 없어서 시영 크롬(로그인 상태)을 화면 조작으로 돌린다 — 예약은 PC에서만 됨, 게시물당 이미지 최대 10장(고객센터 7124474).

## 다운로드 (2026-11-09 시영)
- Downloads 폴더에 미리 복사하지 않는다. 시영이 대시보드에서 **버튼을 눌렀을 때만** 받는다.
  - 맨 위 `이번 주 전체 다운로드` = 주 zip 하나, 안은 `흰지로_카드뉴스_2026-W46/2026-11-10_화_<제목>/01.png…, 캡션.md`. 사실 체크 미완 덱은 빠진다(버튼에 마우스를 올리면 빠진 덱 이름).
  - 뷰어 `전체 한 번에 (zip)` · `이 장만`, 모아 보기의 장마다 `⬇ 받기`.
- zip은 `build.mjs`가 만든다: 덱별 `decks/<덱>/<덱>.zip`, 주별 `dashboard/weeks/흰지로_카드뉴스_<주>.zip`.

## 대시보드 (다크)
- `dashboard/index.html` — 주 단위로 날짜별 덱을 보여 준다. 표지를 누르면 인스타처럼 넘겨 보는 뷰어가 열린다.
- 갱신: `node cardnews/dashboard/build.mjs` (덱 폴더를 훑어서 `dashboard/data.js`를 다시 만든다).

## 덱마다 같이 만드는 것 (2026-11-09 시영)
- `post`: 유튜브 커뮤니티 게시물 글 — **3줄**(2026-11-09 시영). 1줄 = 핵심어 + 후킹(접히기 전에 보이는 자리), 2줄 = 출처·무엇을 정리했나, 3줄 = 댓글을 부르는 질문. + **빈 줄 하나** + 해시태그 1줄(3개) — 공식 근거는 없지만 시영 판단으로 넣음 (2026-11-09). 대시보드 오른쪽 `게시물 글 복사`.

## 덱 상태 값
`초안` → `수정중` → `검수완료` → `발행됨`
- 다른 버전 비교: 덱 폴더 `variants/card-NN@이름.png`(+ 그 버전 `.deck.mjs`)에 넣으면 대시보드 뷰어 그 장에 [원본][이름][나란히 비교] 버튼이 생긴다. 원본은 지우지 않는다.
