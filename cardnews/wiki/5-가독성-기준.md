# 5. 가독성 기준 — "한 장을 3초 안에 읽나" (2026-11-09)

근거: 시영 피드백 + 캐러셀 가이드 조사
- 장당 한 아이디어, 30단어 이하, 2~3초 안에 읽혀야 한다 — [socime](https://socime.io/en/blog/instagram-carousel-best-practices), [instacarousel](https://instacarousel.com/blog/instagram-carousel-guide-2026/)
- 5~8장이 저장·완독에 가장 좋다. 첫 장은 "궁금해서 넘기게" — [carouselli](https://carouselli.com/blog/instagram-carousel-best-practices)
- 꾸밈 없는 글자가 전달력이 좋다. 폰트 1~2개, 색 2~3개 — [크몽](https://kmong.com/article/1013--SNS-%EC%B9%B4%EB%93%9C%EB%89%B4%EC%8A%A4%EB%A5%BC-%EB%A7%8C%EB%93%A4-%EB%95%8C-%EC%95%8C%EC%95%84%EC%95%BC%ED%95%A0-%EB%94%94%EC%9E%90%EC%9D%B8-%ED%8C%81-5%EA%B0%80%EC%A7%80), [툴디](https://www.tooldi.com/social/article/81)

## 우리 기준 (숫자로 검사)
| 항목 | 기준 |
|---|---|
| 덱 길이 | 5~8장 |
| 장당 글 | 헤드라인 2줄(한 줄 12자 안팎) + 보조 1~2줄(40자 안팎). 그 밖의 글 0 |
| 번호 | 순서가 있으면 헤드라인 맨 앞에 `01.` — 헤드라인과 같은 크기 |
| 블록 안 글 | 금지. 유리 판·밝은 블록·이미지 위에 글을 올리지 않는다. 글은 바탕 위 맨 글자로 |
| 같은 말 | 한 장 안에서, 그리고 바닥줄·표지와 겹치는 말 금지 (예: 바닥줄에 이미 `흰지로의 오답노트`가 있으면 본문·라벨에 또 쓰지 않음) |
| 위쪽 라벨 | 쓰지 않는다 (작아서 안 보이고, 헤드라인 번호로 충분) |
| 장 번호 `02 / 10` | 쓰지 않는다 (인스타가 이미 보여 줌) |
| 그림 | 장마다 1개. 그림 안 설명 글은 빼고, 그림 밖 한 줄로 |

## 비워내기 순서 (쓰고 나서 매 장)
1. 이 장의 한 문장은? → 헤드라인이 그 문장인지 확인.
2. 나머지 글을 하나씩 가리고 "없어도 뜻이 통하나?" → 통하면 지운다.
3. 헤드라인과 보조 줄이 같은 말을 하면 보조 줄을 지운다.
4. 그림이 이미 말하는 숫자를 글로 또 쓰지 않는다.
