## 경계
- 기본 테마 = 노트·고딕. 덱마다 source.md(원문 대조표)를 같이 만든다.
- 이 위키 = 매일 올리는 정보형 카드뉴스(인스타·스레드·유튜브 커뮤니티).
- 썸네일·제목 분석 카드뉴스(SET 규칙)는 별개다 → 전역 스킬 `card-news`와 `~/youtube-pd/card-news-agent/`.
- 문체는 `~/youtube-pd/card-news-agent/VOICE.md`를 빌려 쓴다(첫 문장 "사람은 ~", 명사형 종결 금지).
