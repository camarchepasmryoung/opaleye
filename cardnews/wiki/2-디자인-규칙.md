# 2. 디자인 규칙

## 2-0. 규격
- 모든 카드 1080×1080 정방형 (2026-11-09 시영). 노트 테마 가운데 = (540, 540), 표지 가로선·마인드맵 줄기 높이 540.

## 2-1. 테마
- ★기본 = **노트·고딕**(`theme: 'note'` + `font: 'pretendard'`) — 2026-11-09 시영 "노트 고딕이 가장 좋다". 아래 유리판·에디토리얼은 보관용.
- (이전 기본) **유리판**(모션그래픽과 같은 파랑 `#1b35c4` + 오로라 띠 + 유리 판). 코드 `template/glass.mjs`.
- 흰 종이(레퍼런스 직역) = `template/paper.mjs`, 비교용.
- 실측 값·출처 = `template/design-rules.md`.

## 2-2. 바닥줄 (2026-11-09 시영)
- (2026-11-09 최종) 바닥줄 = **가운데 정렬**, 표지는 `출처 · 크리에이터 「원제」`, 나머지 장은 브랜드 `흰지로의 트렌드 노트`. 장수·©는 쓰지 않는다.
- 표지 유튜브 로고 = 공식 아이콘 PNG(`template/assets/youtube_logo.png`)를 **제목 왼쪽 위 모서리에 -12° 기울여 겹친다** (시영 레퍼런스: 썸네일 제목 왼쪽 위 로고). 위쪽 출처 태그는 없앰.
- 마지막 장 = **커뮤니티 글쓰기 CTA**(`noteCta`): "더 궁금한 건 커뮤니티에 직접 글을 남겨 주세요" + 실제 화면 캡처 2단계(채널 '커뮤니티' 버튼 → '어떤 생각을 하고 계신가요?' 상자).
  - 이 장만 예외로 넓게(좌우 50px), 캡처는 종이 질감 위에 선명하게.
  - 강조 = 버튼·상자 실측 크기에 맞춘 **분홍 사각형(질감 없음)** + 분홍 알약 라벨("여기를 눌러요" / "여기에 질문을 적어요"). 손그림 동그라미 X.
  - 캡처는 **로그인 상태 화면**으로 (로그아웃 화면은 글쓰기 상자가 얇은 줄로만 나옴).
- 마지막 장 = 유튜브 커뮤니티 게시물이라 "저장·팔로우" 대신 **"구독"**.

## 2-3. 시각 요소는 매 장 (2026-11-09 시영)
- 장마다 그림이 하나는 있어야 한다: 실제 이미지(썸네일·스크린샷), 도표, 다이어그램.
- 글만 있는 장은 만들지 않는다. 글로 설명할 걸 그림으로 바꿀 수 있는지 먼저 본다.
- 모션(GIF·애니메이션)은 넣지 않는다. 모든 장은 정지 PNG (2026-11-09 시영 "어차피 애니메이션은 안 되니까"). 첫 장 후킹은 글·사진·구도로만.

## 2-4. 한 장 구성
- `01.` 헤드라인 + 그림 1 + 맨 글자 한 줄. 강조 박스는 쓰지 않는다(블록 안 글 금지, [[5-가독성-기준]]).

## 2-5. 테마 3 — 노트 (2026-11-09 시영 "글로만 풀 수 있으면 이렇게")
- 레퍼런스: reputeforge "Storytelling is" 캐러셀 (instagram.com/p/Dbp0bVtIGoh) 9장 역추적. 코드 `template/note.mjs`.
- 종이: 미색 `#F1EFEB` + 가로 섬유 결 + 고운 알갱이 + 가장자리만 거칠게. 질감 층을 **글자 위에 곱하기**로 덮어 잉크가 종이에 스민 느낌. 어둡게 테두리 지는 효과(비네트)는 쓰지 않는다 — 레퍼런스와 100% 크기로 나란히 놓고 맞췄다.
- 모눈: 54px 칸, 연보라 회색 선. 가운데(540, 540)가 선 위에 오게 맞춤. 내용 장에만, 표지·마인드맵·마지막 장은 맨 종이.
- 글자: 명조(Noto Serif KR)만. `1.제목` 번호는 붙여 쓴다. 핵심 단어 1~3개에 색색 손그림 밑줄(분홍·파랑·청록·초록·주황·보라), 표지 핵심어만 형광펜.
- 표지 가로선은 같은 높이(540)로 2장 마인드맵 줄기와 이어진다 → 넘길 때 한 장처럼 보인다.
- 가운데 정렬은 PNG로 잰다: 글 덩어리는 세로 가운데(위·아래 여백 차이 1px 이하), 가로는 덱에서 가장 긴 줄의 좌우 여백이 같게(`inkW`). 바닥줄 `흰지로의 오답노트`는 가운데.
- 고딕 버전: 덱에 `font: 'pretendard'` → Pretendard(제목 650·본문 450). 고딕은 글자 상자가 2.5px 위로 쏠려서 보정함. 가로 가운데용 `inkW`는 글꼴마다 다시 잰다(명조 801 / 고딕 720).

## 2-6. (삭제) 에디토리얼·노트 명조 — 2026-11-09 시영 요청으로 덱·템플릿 삭제. 노트는 고딕만 쓴다.

## 2-7. 글자 크기 (2026-11-09 시영 "전체적으로 더 크게, 내용은 줄이지 말 것") — 11/10 덱부터
- 덱에 `big: true` + 항목 장 `size: 41`(본문), 제목 74px, 표지 제목 +10px, 바닥줄 25px. 마인드맵 이름 46px 그대로(시영이 좋다고 한 기준).
- 본문은 줄이 꺾이면 안 된다 → 내용은 줄이지 말고 줄바꿈 위치만 옮긴다. 검사: 렌더 후 각 줄 nowrap 폭 ≤ 상자 폭.
- 11/09 덱은 예전 크기 그대로(이미 게시됨).
