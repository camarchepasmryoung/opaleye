# 3. 주제 소스 (2026-11-09 시영)

vidIQ 같은 해외 유튜브 전문가 채널만 쓰지 않는다. 섞어서 가져온다.

| 소스 | 예 | 가져오는 방법 |
|---|---|---|
| 해외 유튜브 전문가 영상 | vidIQ, Think Media 등 | 최근 영상 자막 → 한 주제만 뽑기 |
| 요즘 반응 좋은 주제 | 국내외에서 최근 평소보다 크게 터진 영상 | 주간 배치 수집 결과 `data/outliers.json` 재활용 |
| 지금 터진 이슈 설명 | 유튜브 정책·기능 변경, 화제가 된 채널·영상 | 웹 검색으로 최근 1주 뉴스 확인 → "이게 무슨 일인지" 설명 |
| 랜덤 트렌드 | 요즘 유행하는 포맷·밈·편집법 | 웹 검색 + 시영이 던져 주는 링크 |

## 고르는 기준
- 유튜브를 하는 사람이 "이거 나도 해당되네" 할 것.
- 한 문장으로 말할 수 있을 것(→ [[1-기획-규칙]] 1-1).
- 일주일 7개가 한 소스로 몰리지 않게 섞는다.
- 숫자는 원문에 나온 것만 쓰고, 언제 기준인지 붙인다.
